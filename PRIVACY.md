# Política de privacidade

Esta política se aplica ao **AulaFácil Desktop 0.2.x**.

## Resumo

O AulaFácil Desktop funciona localmente no computador. Esta versão não possui
conta on-line, telemetria, publicidade, análise de uso ou sincronização com
servidores.

**Este programa não transfere nenhuma informação para outros sistemas em rede,
a menos que isso seja solicitado especificamente pelo usuário ou pela pessoa
que instala ou opera o programa.**

This program will not transfer any information to other networked systems
unless specifically requested by the user or the person installing or
operating it.

## Dados armazenados

Cadastros, turmas, chamadas, notas, cobranças, recibos e comunicados são
armazenados apenas no perfil local do usuário do Windows, pelo armazenamento da
WebView do aplicativo.

O arquivo de backup JSON somente é criado quando o usuário seleciona a opção de
exportar backup. A restauração somente lê o arquivo que o próprio usuário
selecionar.

## Controle e exclusão

- **Backup e dados > Exportar backup** cria uma cópia para guarda do usuário.
- **Backup e dados > Limpar sistema** apaga os registros do AulaFácil nesta
  instalação depois de uma confirmação explícita.
- A desinstalação é feita em **Configurações do Windows > Aplicativos >
  Aplicativos instalados > AulaFácil > Desinstalar**.

Não coloque senhas, chaves bancárias ou outros segredos nos campos de texto do
sistema ou em arquivos de backup.

## Alterações futuras

Uma versão futura com sincronização, Pix ou aplicativo para responsáveis terá
uma política atualizada antes de ser distribuída. Ela não estará coberta por
esta declaração de funcionamento exclusivamente local.
